# سيرفر ترخيص O2Dialer (مجاني)

يشتغل على Cloudflare Workers + قاعدة D1 (الخطة المجانية). مفيش كروت ولا سيرفر لازم يفضل شغال عندك.

## التركيب (حوالي 15 دقيقة، من المتصفح فقط)
1. اعمل حساب مجاني على cloudflare.com.
2. **Workers & Pages ← Create ← Worker.** سمّيه `o2dialer-server` ← Deploy ← **Edit code**، امسح الكود اللي فيه والصق محتوى `worker.js` كله ← Deploy.
3. **Storage & Databases ← D1 ← Create database** باسم `o2dialer`.
4. ارجع للـ Worker ← **Settings ← Bindings ← Add ← D1 database**: اسم المتغير `DB` والقاعدة `o2dialer` ← Deploy.
5. **Settings ← Variables and Secrets ← Add**: النوع Secret، الاسم `ADMIN_TOKEN`، القيمة نص عشوائي طويل (32 حرف أو أكتر). ده الباسورد بتاع لوحة التحكم. احفظه.
6. افتح `https://o2dialer-server.<اسم-حسابك>.workers.dev/health` لازم يرد `ok`. وبعدها افتح نفس الرابط من غير `/health` وهتظهر لوحة التحكم، ادخل بالـ ADMIN_TOKEN.
7. في GitHub: **Settings ← Secrets and variables ← Actions ← New secret** باسم `LICENSE_URL` وقيمته رابط الـ Worker (من غير `/` في الآخر). بعدها شغّل الـ Build: التطبيق الجديد هيطلب كود تفعيل قبل أي حملة.

الجداول بتتعمل لوحدها أول طلب. مفيش أي أمر لازم تشغّله.

بديل: النشر من GitHub بدل اللصق. حط الـ D1 ID في `wrangler.toml`، وضيف الـ Secrets (`CLOUDFLARE_API_TOKEN` و`CLOUDFLARE_ACCOUNT_ID` و`ADMIN_TOKEN`) وشغّل Workflow اسمه `Deploy license server`.

## لوحة التحكم
- إصدار أكواد (عدد الأجهزة المسموح لكل كود، صلاحية، العمل أوفلاين، استيراد/تصدير) وإلغاؤها.
- قائمة الأجهزة: متصل/غير متصل، الحالة (يتصل/جاهز/متوقف)، اتصالات اليوم، من ردّ، آخر حملة، تقدّم الحملة الحالية، السجل.
- لكل جهاز: **إيقاف/إعادة تفعيل**، صلاحيات (تشغيل الحملات، استيراد أرقام، تصدير ومشاركة)، **وضع الأوفلاين** (إنترنت مطلوب / 24 ساعة / 3 أيام / أسبوع / بدون حد)، تسمية، ملاحظة، حذف.

## إزاي بيشتغل
- **قبل أي حملة** التطبيق بيسأل السيرفر. جهاز موقوف أو من غير إنترنت (وبدون سماح أوفلاين) لا يقدر يبدأ حملة.
- **الحملة الشغالة** مش بتقف لو النت قطع. بتقف بس لو الأدمن أوقف الجهاز أو حذفه (يتم خلال 5 دقايق كحد أقصى، لأن التطبيق بيبلّغ كل 5 دقايق وهو مفتوح).
- **سماح الأوفلاين**: الجهاز يقدر يبدأ حملة من غير نت لمدة محددة من آخر تحقق ناجح. لو الجهاز كان عارف إنه موقوف، بيفضل ممنوع.
- لو حذفت جهاز من اللوحة، بيحتاج كود تفعيل جديد.

## الخصوصية
السيرفر بيخزّن: موديل الجهاز ونسخة أندرويد ونسخة التطبيق، الحالة، عدد المكالمات والردود اليوم، تقدّم الحملة، وتوقيت بدء وانتهاء الحملات. **لا يخزّن أي رقم تليفون ولا اسم ولا محتوى مكالمات.** أبلغ فريقك إن الأجهزة متسجلة.

## حدود الخطة المجانية (تقريبي)
100 ألف طلب يوميا لكل الـ Worker. كل جهاز مفتوح طول اليوم بيعمل حوالي 290 طلب. يعني حوالي 300 جهاز مفتوح طول اليوم. أكتر من كده يحتاج الخطة المدفوعة (5 دولار شهريا).

## ملاحظات أمان صريحة
- الفحص بيتم داخل التطبيق. حد بيعدّل ملف التطبيق نفسه ممكن يتخطاه. التحقق الأونلاين بيمنع الاستخدام العادي، مش الهندسة العكسية.
- جهاز "أوفلاين بدون حد" مش ممكن توقفه عن بُعد وهو من غير نت.
- كود التفعيل لازم يتبعت بشكل خاص. ADMIN_TOKEN لا تشاركه.
